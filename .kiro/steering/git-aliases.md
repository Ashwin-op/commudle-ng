# Git Aliases Quick Reference (oh-my-zsh git plugin)

| Alias | Command |
|-------|---------|
| `glol` | `git log --graph --pretty=oneline-decorated` |
| `gpra` | `git pull --rebase --autostash` |
| `gpsup` | `git push --set-upstream origin <current-branch>` |
| `gpf` | `git push --force-with-lease --force-if-includes` |
| `gpf!` | `git push --force` |
| `gst` | `git status` |
| `gco` | `git checkout` |
| `gcb` | `git checkout -b` |
| `gcmsg` | `git commit -m` |
| `gaa` | `git add --all` |
| `gd` | `git diff` |
| `gl` | `git pull` |
| `gp` | `git push` |
| `grb` | `git rebase` |
| `gsta` | `git stash push` |
| `gstp` | `git stash pop` |

Type `alias | grep git` in terminal to see all available git aliases.
